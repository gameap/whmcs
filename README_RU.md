# Модуль GameAP для WHMCS

Автоматическая выдача игровых серверов в панели [GameAP](https://gameap.com) из
WHMCS. Оплаченный заказ создаёт сервер, неоплата закрывает к нему доступ,
отмена — удаляет. Без участия администратора.

English version: [README.md](README.md) · Deutsche Version: [README_DE.md](README_DE.md) · Versión en español: [README_ES.md](README_ES.md)

## Что делает

| Событие WHMCS | Что происходит в GameAP |
|-----------------|----------------------------------------------------------------|
| Создание | Находит или заводит аккаунт клиента, выбирает ноду, подбирает свободные порты, создаёт сервер, ставит установку в очередь, привязывает сервер к аккаунту и выдаёт клиенту права |
| Приостановка | Останавливает и блокирует сервер — клиент теряет управление |
| Возобновление | Снимает блокировку и, если настроено, запускает сервер |
| Удаление | Отвязывает сервер от аккаунта и удаляет его вместе с файлами (или только отключает, если так настроено) |
| Смена тарифа | Применяет новые лимиты и переменные мода. Игру не меняет |
| Кабинет клиента | Состояние сервера, адрес подключения и вход в панель одной кнопкой |

Ежедневная сверка чинит расхождения только в одну сторону: читает WHMCS,
поправляет панель. Временное состояние биллинга не может уничтожить сервер.
Снимается только блокировка, которую поставил сам модуль; сервер,
заблокированный администратором в панели, остаётся заблокированным.

Пароли аккаунтов панели из WHMCS не меняются: панель не позволяет API-токену
менять пароль существующего аккаунта. Клиент меняет пароль в профиле панели
или через восстановление пароля.

## Требования

- WHMCS 8.9 и новее на PHP 8.1 и новее
- GameAP **4.5.0 и новее** — права токена для доступа к пользователям, нодам и
  играм и эндпоинты единого входа появились в 4.5.0

## Установка

1. Распакуйте архив релиза в корень WHMCS — файлы должны попасть в
   `modules/servers/gameap/`.
2. В панели **под администратором** создайте персональный токен (Профиль →
   API-токены) с правами из [docs/INSTALL.md](docs/INSTALL.md). Токен должен
   принадлежать администратору: панель отклоняет запросы провижна от других
   аккаунтов.
3. В WHMCS откройте **System Settings → Products/Services → Servers** и добавьте
   сервер:
   - **Hostname** — адрес панели
   - **Password** — токен (это поле WHMCS хранит в зашифрованном виде)
   - **Username / Access Hash** — оставьте пустыми
   - **Secure** — включить, если панель работает по HTTPS
   - **Type** — GameAP
4. Нажмите **Test Connection**: проверяются все нужные права, недостающее
   называется поимённо.
5. Создайте продукт типа GameAP и заполните настройки модуля.

## Настройки продукта

Слоты, ОЗУ, ЦП, диск, мод и имя сервера можно переопределять для отдельной
услуги через configurable option или custom field WHMCS с тем же названием;
остальные настройки читаются только из продукта. ОЗУ задаётся в МБ, ЦП — в
процентах ядра (100 = одно ядро), модуль сам переводит их в единицы панели.

## Безопасность

Модуль хранит один секрет — токен панели в поле Password сервера, которое
WHMCS шифрует. В журнал он не попадает: все запросы идут через одну точку
логирования, которая его маскирует, а `$params` не логируется никогда, потому
что содержит и токен, и персональные данные клиента.

Панель отказывается выдавать билет входа для другого администратора, менять
пароли и трогать аккаунты администраторов через токен, поэтому украденный
токен не превращается в доступ к панели. Подробнее — [docs/SECURITY.md](docs/SECURITY.md).

Отчёт об аудите, по итогам которого сделан текущий релиз, — [docs/AUDIT.md](docs/AUDIT.md).
